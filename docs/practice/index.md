# Practice

A question bank for testing recall and design judgement. Items are grouped by topic and use a fixed schema so that coverage, difficulty, and weak areas are easy to see.

## Topics

- Retrieval and search
- Model fundamentals
- Evaluation
- System design and operations
- Agents and tool use
- Security and guardrails
- Modelling choices
- Python and SQL

## Formats

| Format | What it asks for |
| --- | --- |
| `mcq` | One correct option with close distractors. |
| `debug` | A failing system and the first checks to run. |
| `tradeoff` | A choice between two defensible options, with the constraint that decides it. |
| `numerical` | An estimate of cost, latency, or capacity. |
| `design` | An end-to-end design under stated constraints. |
