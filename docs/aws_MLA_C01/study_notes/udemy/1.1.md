# Data Ingestion and Storage - Data basics

### Types of Data
| Type | Description | Examples |
|------|-------------|----------|
| Structured | Data that is organized in a defined manner or schema, typically found in relational databases. | DB tables, CSV files, Excel spreadsheets |
| Unstructured | Data that doesn't have a predefined structure or schema. | Text documents, images, videos, social media posts, emails |
| Semi-structured | Data that has some organizational structure but does not conform to a rigid schema, often containing tags or markers to separate elements. | JSON, XML, HTML, NoSQL databases |

### Properties of Data
| Property | Description | Example |
|----------|-------------|---------|
| Volume | The amount of data generated and stored, often measured in bytes (e.g., terabytes, petabytes). | Social media platform processing TBs of data daily |
| Velocity | Speed at which data is generated, collected, and processed, often in real-time or near real-time. | Stock market data streaming in milliseconds |
| Variety | The diversity of data types and sources, including structured, unstructured, and semi-structured data. | Multiple data sources with varying formats and structures |

### Data Warehouses vs Data Lakes
| Feature | Data Warehouse | Data Lake |
|---------|----------------|-----------|
| Purpose | Optimized for structured data and analytics, often used for business intelligence and reporting. | Designed to store large volumes of raw, unstructured, and semi-structured data for future processing and analysis. |
| Schema | Schema-on-write, requiring data to be structured before storage. <br> **ETL** | Schema-on-read, allowing data to be stored in its raw form and structured when read. <br> **ELT** |
| Choose when... | You need fast query performance on structured data for analytics and reporting. | You want to store diverse data types for future analysis, machine learning, or big data processing. |
| Example | Amazon Redshift | Amazon S3 with AWS Lake Formation |

### ETL Pipelines - AWS Glue
- Extract
    - Retrieve raw data from various sources
    - Ensure data integrity and quality during extraction
    - Real-time / batches, depending on requirements
- Transform
    - Convert and map data from one raw form to suitable format for target warehouse
    - Cleansing, enrichment, format changes, aggregations, computations, encoding, missing values handling, ...
- Load
    - Insert the transformed data into a target database or data warehouse
    - Streaming / batches

### Data Formats
| Format | Description | Use Cases |
|--------|-------------|-----------|
| CSV | Comma-separated values, a simple text format for tabular data. | Data exchange, spreadsheets, and simple data storage. |
| JSON | JavaScript Object Notation, a lightweight data interchange format that is easy for humans to read and write, and easy for machines to parse and generate. | Web APIs, configuration files, and data serialization. |
| Avro | A binary serialization format that is compact, fast, and suitable for data exchange between systems. | Big data processing, data serialization, and RPC (Remote Procedure Call) frameworks. |
| Parquet | A columnar storage file format optimized for large-scale data processing and analytics. | Data warehousing, big data analytics, and machine learning pipelines. |
