# Data Transformation, Integrity and Feature Engineering - Elastic MapReduce (EMR)

### EMR Structure
```mermaid
graph TD
    subgraph EMR ["Amazon EMR Cluster"]
        Master["<b>Master Node</b><br/>• Cluster Orchestration & Management<br/>• Runs NameNode / ResourceManager<br/>• <i>On-Demand / Reserved Instance</i>"]

        subgraph CoreGroup ["Core Instance Group"]
            Core1["<b>Core Node 1</b><br/>Compute + HDFS Data Storage"]
            Core2["<b>Core Node 2</b><br/>Compute + HDFS Data Storage"]
        end

        subgraph TaskGroup ["Task Instance Group"]
            Task1["<b>Task Node 1</b><br/>Compute ONLY (No HDFS)<br/>• <i>Spot Instance</i>"]
            Task2["<b>Task Node 2</b><br/>Compute ONLY (No HDFS)<br/>• <i>Spot Instance</i>"]
        end
    end

    S3[("<b>Amazon S3</b><br/>(EMRFS Persistent Data Lake)")]

    %% Orchestration Flow
    Master ==>|"Orchestrates Tasks & HDFS"| CoreGroup
    Master ==>|"Assigns Compute Tasks"| TaskGroup

    %% Data Flow
    CoreGroup <==>|"Read / Write Data"| S3
    TaskGroup <==>|"Read / Write Data"| S3
```
