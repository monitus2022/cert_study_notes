# Coding & SQL

Short, timed drills. The goal is to reproduce a primitive, a parser, or a query from memory under a constraint, not to finish a large problem.

Each track has one example page that shows the format.

## Tracks

| Track | Focus |
| --- | --- |
| [Python](python/index.md) | Applied AI primitives, data handling, retries, and token accounting. |
| [JSON](json/index.md) | Structured output, schema validation, streaming, and tool payloads. |
| [SQL](sql/index.md) | Joins, window functions, deduplication, and incremental loads. |

## Format

Each drill page contains: prompt, constraints, starter, tests, and solution notes. Target time is 15–20 minutes.
