# JSON

JSON drills focus on the boundary between a model and the rest of the system: parsing output, validating shape, handling partial streams, and keeping tool payloads small.

## Topics

- Parse a model response into a typed object.
- Validate against a JSON Schema and return a useful error.
- Handle markdown fences, trailing commas, and partial JSON during streaming.
- Design a compact tool payload and a stable response envelope.
- Merge or diff nested JSON without losing unknown fields.
