### Question 1
A company is designing an application that must run in a specific geographic area. The application should be deployed across separate data center locations within that geographic area to improve availability. Which AWS global infrastructure concept best describes the geographic area?

A. AWS Region  
B. Availability Zone  
C. Edge location  
D. AWS Local Zone  

<details>
<summary>Click to view Answer & Explanation</summary>

**Correct Answer:** A

**Explanation:**

* **Why A is correct:** An AWS Region is a separate geographic area that contains multiple Availability Zones.
* **Why distractors are incorrect:**
  * **B (Availability Zone):** An Availability Zone is one or more discrete data centers within an AWS Region.
  * **C (Edge location):** An edge location is a site used to deliver content and services closer to end users.
  * **D (AWS Local Zone):** An AWS Local Zone places selected AWS resources closer to users in a specific metropolitan area, but it is not the broader geographic area containing multiple Availability Zones.

</details>

<summary>Click to view Answer & Explanation</summary>
