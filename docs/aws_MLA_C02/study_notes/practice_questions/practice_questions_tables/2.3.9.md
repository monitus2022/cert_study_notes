| **### Question 1 - Automated Content Quality Validation via LLM-as-a-Judge**<br><br>A media company is building a generative AI application using Amazon Bedrock to summarize daily news articles. The engineering team needs to evaluate the summarization quality of multiple Foundation Models (FMs) across a large dataset of 5,000 articles. The evaluation must be highly scalable, automated, and must provide a rationale for each assigned score to ensure transparency.<br><br>Which solution meets these requirements with the **LEAST operational overhead**?<br><br>- **A)** Deploy a custom AWS Lambda function that calculates the ROUGE-1 score for each generated summary against a reference summary and stores the results in Amazon S3.<br>- **B)** Use Amazon SageMaker Shadow Testing to deploy a candidate FM alongside a production FM and route live traffic to compare the summaries.<br>- **C)** Create an Amazon Bedrock Evaluation job using the LLM-as-a-judge framework, selecting a capable model to score the summaries and provide reasoning for the scores.<br>- **D)** Build a custom evaluation pipeline using Amazon SageMaker Processing jobs that runs a Hugging Face BERTScore implementation on the 5,000 articles. | **Correct Answer:** **C**<br><br>**Correct Answer Analysis:**<br>- **C is Correct:** Amazon Bedrock Evaluations natively supports the LLM-as-a-judge framework, allowing an automated model to score the outputs of other models across large datasets. | **### Question 3 - Isolating RAG Generation Failures**<br><br>A Retrieval-Augmented Generation (RAG) application built on Amazon Bedrock Knowledge Bases is generating highly fluent answers, but users report that the answers frequently omit critical facts that are verifiably present in the retrieved source documents. The engineering team must perform an AI evaluation to isolate whether the issue is a retrieval failure or a generation failure.<br><br>Which **TWO** evaluation metrics should the team use to determine if the LLM is accurately utilizing the retrieved context? (Select TWO)<br><br>- **A)** Context Precision<br>- **B)** Context Recall<br>- **C)** Context Utilization (Faithfulness)<br>- **D)** Answer Relevance<br>- **E)** Semantic Similarity | **Correct Answers:** **C** and **D**<br><br>**Correct Answer Analysis:**<br>- **C is Correct:** Context Utilization (often measured as Faithfulness) assesses whether the generated answer contains only facts that are supported by the retrieved context, ensuring the model isn't hallucinating or dropping retrieved facts.<br>- **D is Correct:** Answer Relevance evaluates whether the generated response actually addresses the user's prompt, isolating the generation step's effectiveness.<br><br>**Distractor Analysis:**<br>- **A is Incorrect:** Context Precision measures whether the retrieval step returned relevant chunks, not whether the generation step utilized them.<br>- **B is Incorrect:** Context Recall evaluates if the retrieval step successfully fetched all necessary ground-truth facts, a retrieval metric, not a generation metric.<br>- **E is Incorrect:** Semantic Similarity generally compares the generated answer to a reference answer, but does not specifically isolate whether the LLM utilized the retrieved context.<br><br>> **Key Takeaway:** To isolate generation failures in RAG, evaluate Context Utilization (Faithfulness) and Answer Relevance, separate from retrieval metrics like Context Precision and Recall. |

| **### Question 6 - Customizing LLM-as-a-Judge Criteria**<br><br>A retail company is configuring an LLM-as-a-judge evaluation in Amazon Bedrock to assess the helpfulness of their customer service chatbot. Furthermore, to improve the reliability of the judge, they need the judge to provide a reasoning step before assigning the final score.<br><br>How should the team configure the LLM-as-a-judge evaluation to meet these requirements?<br><br>- **A)** Use a programmatic evaluation job and configure the BLEU score threshold.<br>- **B)** Select a human evaluation workflow and provide a 1-to-5 rubric to the human raters.<br>- **C)** Define a custom prompt template for the LLM-as-a-judge that includes the specific scoring criteria and a chain-of-thought instruction to output reasoning before the score.<br>- **D)** Deploy the judge model on a SageMaker Real-Time endpoint and pass the chatbot output via a custom Boto3 script. | **Correct Answer:** **C**<br><br>**Correct Answer Analysis:**<br>- **C is Correct:** In Amazon Bedrock Evaluations, LLM-as-a-judge can be highly customized using prompt templates. The team can define specific criteria (clarity, tone, accuracy), specify the 1-5 scale, and instruct the model to output its reasoning (chain-of-thought) before the final score, ensuring reliable and transparent evaluation.<br><br>**Distractor Analysis:**<br>- **A is Incorrect:** Programmatic evaluations compute mathematical metrics like BLEU and do not use an LLM to judge clarity or tone.<br>- **B is Incorrect:** The scenario specifies using an LLM-as-a-judge (automated model), not human raters.<br>- **D is Incorrect:** Deploying a custom SageMaker endpoint and writing custom Boto3 scripts introduces unnecessary operational overhead compared to the native Bedrock Evaluation LLM-as-a-judge configuration.<br><br>> **Key Takeaway:** LLM-as-a-judge in Bedrock can be customized with prompt templates to enforce specific scoring rubrics and chain-of-thought reasoning for higher evaluation fidelity. |
| **### Question 7 - Programmatic N-gram Overlap Metrics**<br><br>A localization team is evaluating an FM's capability to translate technical manuals from English to Spanish. They have a dataset of source texts and high-quality reference human translations. To establish a baseline, they want to compute a metric that directly compares the exact word-level overlap (n-grams) of the FM's output with the reference translation.<br><br>Which evaluation metric should they use in an Amazon Bedrock Evaluation job?<br><br>- **A)** BERTScore<br>- **B)** Semantic Similarity<br>- **C)** BLEU<br>- **D)** LLM-as-a-judge<br><br>Select ONE that applies. | **Correct Answer:** **C**<br><br>**Correct Answer Analysis:**<br>- **C is Correct:** BLEU (Bilingual Evaluation Understudy) is a programmatic evaluation metric that measures the exact n-gram overlap between a generated text and a reference text. It is widely used for machine translation evaluation to assess lexical accuracy.<br><br>**Distractor Analysis:**<br>- **A is Incorrect:** BERTScore uses contextual embeddings to measure semantic similarity, not exact word-level n-gram overlap.<br>- **B is Incorrect:** Semantic Similarity evaluates meaning and context, allowing for different word choices, whereas the requirement specifically asks for exact word-level overlap.<br>- **D is Incorrect:** LLM-as-a-judge uses a language model to subjectively score the output based on custom criteria, rather than computing a deterministic mathematical n-gram overlap.<br><br>> **Key Takeaway:** Use BLEU or ROUGE for programmatic, exact n-gram overlap evaluation, and use BERTScore or LLM-as-a-judge for semantic or subjective quality assessment. |

| **### Question 9 - Evaluating Answer Relevance for Customer Service Bots**<br><br>A customer service bot powered by Amazon Bedrock is generating responses to user queries. The team needs to implement an AI evaluation metric to measure how well the generated answers align with the intent of the user's prompt.<br><br>Which evaluation metric should the team configure?<br><br>- **A)** Context Utilization<br>- **B)** Answer Relevance<br>- **C)** Context Recall<br>- **D)** Toxicity<br><br>Select ONE that applies. | **Correct Answer:** **B**<br><br>**Correct Answer Analysis:**<br>- **B is Correct:** Answer Relevance is a metric used in GenAI evaluation (often computed via LLM-as-a-judge or semantic similarity) specifically to evaluate whether the generated response actually addresses the core intent of the user's prompt or question.<br><br>**Distractor Analysis:**<br>- **A is Incorrect:** Context Utilization (Faithfulness) evaluates if the generated answer relies only on the provided retrieved context, not whether it answers the prompt.<br>- **C is Incorrect:** Context Recall evaluates if the retrieval system successfully fetched all the necessary information from the knowledge base, a retrieval metric rather than a generation metric.<br>- **D is Incorrect:** Toxicity measures the safety and harmfulness of the text, not its relevance to the user's query.<br><br>> **Key Takeaway:** Answer Relevance specifically evaluates if the generated output directly addresses the user's prompt, isolating prompt comprehension from factual accuracy. |
