| **### Question 4 - Median vs. Mean Imputation for Outliers**<br><br>A manufacturing company is building a predictive maintenance model. Sensor data contains missing values in the `temperature` column. The data is heavily skewed due to occasional extreme overheating events (outliers). The ML engineer decides to impute missing values with the median rather than the mean.<br><br>What is the primary impact of this decision on the imputed dataset?<br><br>- **A)** It will pull the dataset's distribution toward the middle and significantly decrease variance.<br>- **B)** It preserves the original distribution of the dataset exactly.<br>- **C)** It minimizes the influence of extreme outlier values on the imputed data compared to using the mean.<br>- **D)** It converts the `temperature` column into a categorical feature. | **Correct Answer:** **C**<br><br>**Correct Answer Analysis:**<br>- **C is Correct:** The median is the middle value of a sorted dataset and is robust to outliers. By imputing with the median instead of the mean, the imputed values will not be artificially skewed by the extreme overheating events, preserving a more realistic center for the missing data.<br><br>**Distractor Analysis:**<br>- **A is Incorrect:** Pulling the distribution toward the middle and decreasing variance is the effect of mean imputation, not median imputation.<br>- **B is Incorrect:** Imputation cannot preserve the original distribution exactly; it substitutes missing values with a constant (the median), which slightly alters the shape and variance.<br>- **D is Incorrect:** Imputing a numeric column with its median retains its continuous numeric data type; it does not convert it to a categorical feature.<br><br>> **Key Takeaway:** When a dataset contains extreme outliers, median imputation is preferred over mean imputation because the median is robust to outliers and prevents extreme values from skewing the imputed data. |

| **### Question 9 - Consequence of Dropping Missing Rows**<br><br>A data science team is preparing a dataset for a binary classification model. A critical feature, `user_age`, has 5% missing values. The team decides to drop the rows with missing values rather than imputing them.<br><br>What is the primary consequence of this decision on the remaining dataset?<br><br>- **A)** It preserves the original statistical distribution of the remaining `user_age` data but loses the other features in those rows.<br>- **B)** It pulls the distribution of the `user_age` data toward the middle and decreases variance.<br>- **C)** It artificially increases the variance of the `user_age` column.<br>- **D)** It automatically resolves any class imbalance in the target variable. | **Correct Answer:** **A**<br><br>**Correct Answer Analysis:**<br>- **A is Correct:** Dropping rows with missing values (listwise deletion) ensures that the statistical distribution of the observed `user_age` values is not altered by artificial imputation. However, the tradeoff is the loss of all other feature data contained in those discarded rows.<br><br>**Distractor Analysis:**<br>- **B is Incorrect:** Pulling the distribution toward the middle and decreasing variance is the effect of mean imputation, not dropping rows.<br>- **C is Incorrect:** Dropping rows with missing values does not inherently increase the variance of the observed data; it simply truncates the dataset.<br>- **D is Incorrect:** Dropping rows with missing features has no guaranteed relationship to the target variable's class balance; it could potentially worsen class imbalance if the missing values correlate with the minority class.<br><br>> **Key Takeaway:** Dropping rows with missing data preserves the feature's original statistical distribution but sacrifices the totality of data points in those rows, which can reduce model training volume. |
