| **### Question 1 - Choosing the Right SageMaker Built-in Algorithm for Tabular Data**<br><br>A retail company needs to train a binary classification model to predict customer churn based on a large, structured tabular dataset stored in Amazon S3. The data science team has limited engineering resources and wants the most cost-effective solution with the least operational overhead. They prefer not to write custom training loops or manage Docker containers.<br><br>Which approach satisfies these requirements?<br><br>- **A)** Write a custom PyTorch training script using SageMaker Script Mode.<br>- **B)** Use the Amazon SageMaker XGBoost built-in algorithm.<br>- **C)** Use the Amazon SageMaker BlazingText built-in algorithm.<br>- **D)** Build a custom Docker container (BYOC) with scikit-learn and register it in Amazon ECR.<br><br>*(Select ONE)* | **Correct Answer:** **B**<br><br>**Correct Answer Analysis:**<br>- **B is Correct:** The SageMaker XGBoost built-in algorithm is specifically optimized for structured/tabular data. Using a built-in algorithm eliminates the need to write custom training loops or manage containers, providing the lowest operational overhead.<br><br>**Distractor Analysis:**<br>- **A is Incorrect:** Using SageMaker Script Mode with PyTorch introduces unnecessary operational overhead for a standard tabular classification task, as it requires writing and maintaining a custom training script.<br>- **C is Incorrect:** BlazingText is a built-in algorithm designed for natural language processing (NLP) tasks like text classification and word2vec, not structured tabular data.<br>- **D is Incorrect:** Bringing Your Own Container (BYOC) requires building, testing, pushing, and maintaining a custom Docker image in Amazon ECR, directly violating the constraint of least operational overhead.<br><br>> **Exam Tip / AWS Best Practice:** For standard tabular regression or classification tasks, always prefer SageMaker built-in algorithms (like XGBoost or Linear Learner) to minimize operational overhead and infrastructure management. |

| **### Question 10 - Hyperparameter Tuning with Built-in Algorithms**<br><br>An organization is using the SageMaker K-Means built-in algorithm to cluster customers into behavioral segments.
