| **### Question 1 - Structural Validation of Prompt-Response Pairs**<br><br>An ML engineering team is preparing a JSONL dataset for fine-tuning a large language model (LLM) in Amazon Bedrock. The dataset consists of prompt-response pairs, and compliance rules dictate that every record must contain both a "prompt" and a "completion" field, neither of which can be empty. The team needs to enforce these structural rules with the least operational overhead before the data is used for training.<br><br>Which solution meets these requirements? (Select ONE)<br><br>- **A)** Use Amazon Macie to scan the S3 bucket for empty fields in JSONL files.<br>- **B)** Use AWS Glue Data Quality with a Data Quality Definition Language (DQDL) ruleset to check for column presence and non-empty values.<br>- **C)** Use Amazon Bedrock Guardrails to set up content filters that block empty prompts.<br>- **D)** Write a custom AWS Lambda function to parse the JSONL file and log missing fields to CloudWatch. | **Correct Answer:** **B**<br><br>**Correct Answer Analysis:**<br>- **B is Correct:** AWS Glue Data Quality allows engineers to declare explicit, repeatable rules (e.g., `Completeness "prompt" = 1.0` and `ColumnLength "prompt" > 0`) in DQDL, evaluating the dataset automatically with minimal operational overhead.<br><br>**Distractor Analysis:**<br>- **A is Incorrect:** Amazon Macie is designed for sensitive data (PII) discovery and security classification, not structural schema validation of JSONL fields.<br>- **C is Incorrect:** Amazon Bedrock Guardrails screens model inputs/outputs at inference time for safety, toxicity, and denied topics, not structural completeness of training datasets.<br>- **D is Incorrect:** Writing and maintaining custom Lambda code to parse JSON and log errors introduces unnecessary operational overhead compared to a declarative Glue Data Quality ruleset.<br><br>> **Exam Tip:** Use AWS Glue Data Quality (DQDL) for declarative structural and schema validation of datasets, and reserve Bedrock Guardrails for content safety screening. |
| **### Question 2 - Content Safety Screening with Bedrock Guardrails**<br><br>A generative AI team is collecting customer service chat transcripts to use as a prompt-response training dataset for a custom model. Before ingesting this data into the training pipeline, the team must ensure that no prompts or responses contain hate speech, explicit content, or request forbidden topics. The organization mandates using a fully managed AWS service to screen the text without maintaining custom moderation models.<br><br>Which AWS service fulfills this requirement natively? (Select ONE)<br><br>- **A)** Amazon Rekognition<br>- **B)** AWS Glue DataBrew<br>- **C)** Amazon Bedrock Guardrails<br>- **D)** Amazon SageMaker Ground Truth | **Correct Answer:** **C**<br><br>**Correct Answer Analysis:**<br>- **C is Correct:** Amazon Bedrock Guardrails provides configurable filters (content filters, denied topics, word filters) specifically designed to screen prompts and model responses, which can be applied during the data preparation phase to filter harmful content.<br><br>**Distractor Analysis:**<br>- **A is Incorrect:** Amazon Rekognition provides image and video moderation, not text-based prompt-response content screening.<br>- **B is Incorrect:** AWS Glue DataBrew is used for data profiling and cleaning (e.g., missing values, outliers), not for semantic content safety or toxicity moderation.<br>- **D is Incorrect:** Amazon SageMaker Ground Truth is a data labeling service for human annotation, not an automated content safety screening tool.<br><br>> **Exam Tip:** Bedrock Guardrails is the go-to service for screening text for safety, toxicity, and denied topics in generative AI workflows. |
| **### Question 3 - PII Detection in Text Training Data**<br><br>An enterprise is preparing a large text corpus of email interactions for fine-tuning a foundation model. Compliance policies require that all personally identifiable information (PII), such as social security numbers and credit card numbers, be identified and redacted from the prompt-response pairs before training begins. The solution must use an AWS native service optimized for text analysis.<br><br>Which service should the team use? (Select ONE)<br><br>- **A)** Amazon Macie<br>- **B)** Amazon Comprehend<br>- **C)** Amazon SageMaker Data Wrangler<br>- **D)** AWS Glue Data Quality | **Correct Answer:** **B**<br><br>**Correct Answer Analysis:**<br>- **B is Correct:** Amazon Comprehend natively detects PII entities (such as SSNs, credit card numbers, names) in English and Spanish text, supporting both cleaning and safety screening for training data integrity.<br><br>**Distractor Analysis:**<br>- **A is Incorrect:** Amazon Macie is a data security service that discovers and protects sensitive data in Amazon S3 buckets; it is not an inline text analysis API for prompt-response pairs.<br>- **C is Incorrect:** Amazon SageMaker Data Wrangler is used for interactive data transformations and imbalance correction, not pre-trained PII entity extraction.<br>- **D is Incorrect:** AWS Glue Data Quality evaluates dataset rules (e.g., schema, ranges), but it cannot perform natural language processing (NLP) to semantically identify PII.<br><br>> **Exam Tip:** Use Amazon Comprehend for extracting PII from text datasets, and Amazon Macie for securing the S3 buckets that store those datasets. |
| **### Question 4 - Enforcing Denied Topics in Training Data**<br><br>A financial services company is preparing a dataset to fine-tune an LLM for internal Q&A. The compliance team has defined a strict list of prohibited topics, such as "investment advice" and "stock predictions," which must not be present in any of the prompt-response pairs. The AI engineer needs to screen the dataset and filter out any records containing these denied topics with the least custom code.<br><br>Which AWS service provides the required capability natively? (Select ONE)<br><br>- **A)** Amazon Bedrock Guardrails<br>- **B)** AWS Glue Data Quality<br>- **C)** Amazon Comprehend Medical<br>- **D)** Amazon Rekognition | **Correct Answer:** **A**<br><br>**Correct Answer Analysis:**<br>- **A is Correct:** Amazon Bedrock Guardrails features "Denied Topics" filters, allowing administrators to define specific topics to block. Running the dataset through Guardrails screens the prompts and responses for these prohibited subjects.<br><br>**Distractor Analysis:**<br>- **B is Incorrect:** AWS Glue Data Quality uses DQDL for structural and statistical rules (e.g., completeness, ranges) but cannot understand semantic topics in natural language.<br>- **C is Incorrect:** Amazon Comprehend Medical is tailored for medical and clinical text entity extraction, not financial compliance denied topics.<br>- **D is Incorrect:** Amazon Rekognition handles image and video analysis, not text-based topic filtering.<br><br>> **Exam Tip:** When the requirement involves semantic understanding of text (like prohibited topics or harmful intent), look to Bedrock Guardrails or Comprehend, not Glue Data Quality. |
| **### Question 5 - Validating Response Length Constraints**<br><br>An AI engineering team is setting up a continuous ingestion pipeline to validate prompt-response pairs stored in Amazon S3. The pipeline must first verify that every JSON record has a `response` field with a maximum length of 500 characters. The team wants to use the most cost-effective and operationally efficient method for the structural length check.<br><br>Which approach should they use for the structural validation step? (Select ONE)<br><br>- **A)** Use Amazon Comprehend to analyze the text length and toxicity.<br>- **B)** Use AWS Glue Data Quality to enforce a DQDL rule such as `ColumnLength "response" <= 500`.<br>- **C)** Use Amazon Bedrock Guardrails to enforce a word limit on the model's response.<br>- **D)** Deploy a custom Amazon SageMaker Processing job with a Python script to count characters. | **Correct Answer:** **B**<br><br>**Correct Answer Analysis:**<br>- **B is Correct:** AWS Glue Data Quality allows you to write declarative rules in DQDL, such as `ColumnLength`, to validate structural constraints on datasets cost-effectively without writing custom code.<br><br>**Distractor Analysis:**<br>- **A is Incorrect:** Amazon Comprehend is an NLP service for entity detection and sentiment analysis, not structural field validation like character length.<br>- **C is Incorrect:** Amazon Bedrock Guardrails is used for safety and content filtering at inference time, not for validating the character length of files in an S3 training dataset.<br>- **D is Incorrect:** A custom SageMaker Processing job requires writing and maintaining code, which introduces higher operational overhead compared to a declarative Glue ruleset.<br><br>> **Exam Tip:** For simple structural validations like string lengths, null counts, or value ranges, AWS Glue Data Quality is the most efficient choice. |

| **### Question 7 - Dropping Missing Prompts in Data Wrangler**<br><br>An ML team is using Amazon SageMaker Data Wrangler to prepare a dataset of prompt-response pairs for training. During the data preparation phase, they discover that some prompts contain missing values or are completely empty. The team needs to handle this with the least manual intervention while ensuring the resulting dataset is structurally sound.<br><br>Which Data Wrangler transformation should the engineer apply? (Select ONE)<br><br>- **A)** Convert the prompt column to a categorical feature.<br>- **B)** Use the "Drop missing" transformation on the prompt column.<br>- **C)** Apply mean imputation to the prompt text column.<br>- **D)** Use Amazon Bedrock Guardrails to filter out empty prompts. | **Correct Answer:** **B**<br><br>**Correct Answer Analysis:**<br>- **B is Correct:** The "Drop missing" transformation in SageMaker Data Wrangler removes rows with null or empty values, cleanly addressing the structural defect and ensuring only valid pairs remain.<br><br>**Distractor Analysis:**<br>- **A is Incorrect:** Converting text to a categorical feature is a modeling transformation, not a cleaning step for missing text data.<br>- **C is Incorrect:** Mean imputation applies to numeric columns; you cannot calculate the "mean" of a text prompt.<br>- **D is Incorrect:** Bedrock Guardrails is used for content safety, not for fixing missing values inside a SageMaker Data Wrangler data flow.<br><br>> **Exam Tip:** Missing numeric values might be imputed, but missing text prompts or categorical labels should typically be dropped to avoid teaching the model incorrect associations. |
| **### Question 8 - Orchestrating the Validation Pipeline**<br><br>A generative AI team needs to orchestrate a validation pipeline for prompt-response pairs. The pipeline must execute three sequential steps: checking the JSONL schema using AWS Glue, screening for toxic content using Amazon Comprehend, and finally moving the validated data to a secure S3 bucket. The solution must minimize the code required to manage the state and retries of these steps.<br><br>Which AWS service is best suited for this orchestration? (Select ONE)<br><br>- **A)** AWS Step Functions<br>- **B)** Amazon EventBridge<br>- **C)** Amazon SageMaker Pipelines<br>- **D)** AWS Glue Workflows | **Correct Answer:** **A**<br><br>**Correct Answer Analysis:**<br>- **A is Correct:** AWS Step Functions is a serverless orchestration service that allows you to sequence AWS services (like Glue and Comprehend) while handling state management, retries, and error handling with minimal custom code.<br><br>**Distractor Analysis:**<br>- **B is Incorrect:** Amazon EventBridge is used for event routing and scheduling, not for managing complex multi-step workflow states and sequential dependencies.<br>- **C is Incorrect:** Amazon SageMaker Pipelines is optimized for ML training and deployment workflows, whereas this is a data validation ETL pipeline mixing non-SageMaker services.<br>- **D is Incorrect:** AWS Glue Workflows is restricted to orchestrating Glue components (jobs, crawlers, triggers) and cannot natively orchestrate Amazon Comprehend jobs.<br><br>> **Exam Tip:** For mixed-service orchestration (e.g., Glue + Comprehend + S3) requiring state management and retries, use AWS Step Functions. |
