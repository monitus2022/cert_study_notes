| **### Question 1 - Continuous Pre-training Data Preparation**<br><br>A financial institution wants to adapt a foundation model to understand complex, proprietary financial jargon and writing styles. They have a massive corpus of unlabeled financial research reports, historical memos, and proprietary notes. The ML team wants to update the model's internal weights to absorb this domain-specific vocabulary.<br><br>Which data preparation approach matches this goal with the **least operational overhead**? (Select ONE)<br><br>- **A)** Create JSONL files of prompt-completion pairs.<br>- **B)** Assemble the unlabeled domain text in plain text or JSONL format.<br>- **C)** Extract embeddings for the text and store in OpenSearch.<br>- **D)** Build a prompt set for a teacher model to generate responses. | **Correct Answer:** **B**<br><br>**Correct Option Analysis:**<br>- **B is Correct:** Continuous pre-training (also known as domain adaptation) uses self-supervised learning on large volumes of unlabeled text. Assembling the raw, unlabeled text without creating prompt-response pairs is the correct and lowest-overhead preparation method for this customization path.<br><br>**Distractor Analysis:**<br>- **A is Incorrect:** Prompt-completion pairs are required for supervised fine-tuning (SFT), not continuous pre-training. Pre-training ignores the pairing and just uses the text distribution.<br>- **C is Incorrect:** Embedding text and storing it in OpenSearch is the preparation step for a Retrieval-Augmented Generation (RAG) pipeline, which does not update the model's weights.<br>- **D is Incorrect:** Building a prompt set for a teacher model is the data preparation step for model distillation, not continuous pre-training.<br><br>> **Exam Tip:** Continuous pre-training absorbs vocabulary and style from unlabeled text; fine-tuning learns tasks from labeled pairs. |
| **### Question 2 - Model Distillation Data Artifacts**<br><br>An enterprise is building a customer service chatbot and wants to use a smaller, cost-effective foundation model. They have a larger, highly capable model that performs well but is too expensive to run in production. The team decides to use Amazon Bedrock model distillation.<br><br>The team must prepare the training artifacts for the smaller model with **minimal manual labeling effort**. What data preparation step is required for this distillation process? (Select ONE)<br><br>- **A)** Prepare a large dataset of unlabeled domain text.<br>- **B)** Manually label thousands of prompt-response pairs for the smaller model.<br>- **C)** Assemble a diverse set of prompts covering the target use cases.<br>- **D)** Convert the customer service documents into vector embeddings. | **Correct Answer:** **C**<br><br>**Correct Option Analysis:**<br>- **C is Correct:** For model distillation, the primary data artifact prepared by the user is a set of prompts covering the target use cases. The managed distillation path uses the larger "teacher" model to generate responses to these prompts, which are then used to fine-tune the smaller "student" model, avoiding manual response labeling.<br><br>**Distractor Analysis:**<br>- **A is Incorrect:** Unlabeled domain text is used for continuous pre-training, not distillation.<br>- **B is Incorrect:** The key advantage of distillation is avoiding manual labeling of responses; the teacher model generates them.<br>- **D is Incorrect:** Vector embeddings are for RAG pipelines, not for distilling model weights.<br><br>> **Exam Tip:** Distillation requires a prompt set; the teacher model generates the responses to train the student model. |
| **### Question 3 - Fine-Tuning Data Formatting**<br><br>A healthcare startup is preparing data to fine-tune an Amazon Bedrock foundation model for a specific task: extracting patient symptoms from clinical notes and outputting them in a structured JSON format. The startup has 10,000 examples of clinical notes and the corresponding correct JSON outputs.<br><br>The data must be formatted according to Bedrock fine-tuning requirements. How should the data be prepared? (Select ONE)<br><br>- **A)** Save the dataset as CSV files with separate columns for prompts and completions.<br>- **B)** Store the unlabeled clinical notes in an S3 bucket for continued pre-training.<br>- **C)** Format the data as JSONL files with prompt-completion pairs.<br>- **D)** Chunk the clinical notes and generate embeddings using Amazon Titan. | **Correct Answer:** **C**<br><br>**Correct Option Analysis:**<br>- **C is Correct:** Amazon Bedrock supervised fine-tuning requires labeled examples supplied as JSONL (JSON Lines) files in a specific schema, typically containing prompt and completion pairs.<br><br>**Distractor Analysis:**<br>- **A is Incorrect:** While CSV can hold tabular data, Amazon Bedrock fine-tuning natively expects JSONL for prompt-completion pairs, not CSV.<br>- **B is Incorrect:** Storing unlabeled notes is for continuous pre-training; this scenario requires supervised fine-tuning since they have the corresponding correct JSON outputs (labels).<br>- **D is Incorrect:** Chunking and generating embeddings is for RAG, not for fine-tuning a model to output structured JSON.<br><br>> **Exam Tip:** Amazon Bedrock supervised fine-tuning natively consumes JSONL files containing prompt and completion pairs. |
| **### Question 4 - Redacting PII for Pre-training**<br><br>A legal firm is preparing data for continuous pre-training of a foundation model on proprietary legal case files. The data contains highly sensitive Personally Identifiable Information (PII) of clients. Compliance policies mandate that PII must be completely removed before the data is used for any model training, ensuring it cannot surface in model outputs.<br><br>Which approach satisfies this **zero data retention** compliance requirement? (Select ONE)<br><br>- **A)** Mask the PII using AWS Glue DataBrew, replacing names with "[REDACTED]".<br>- **B)** Use Amazon Comprehend to detect PII entities, then drop the records containing PII or remove the entities completely before continuous pre-training.<br>- **C)** Fine-tune the model instead of continuous pre-training, as fine-tuning inherently prevents PII leakage.<br>- **D)** Use AWS Lambda to replace PII with hashed values, as hashing guarantees PII cannot be reverse-engineered by the model. | **Correct Answer:** **B**<br><br>**Correct Option Analysis:**<br>- **B is Correct:** Redaction removes the PII entirely or drops the record. Amazon Comprehend can detect PII entities in text, allowing the engineering team to strip the sensitive data out before the text is sent for continuous pre-training.<br><br>**Distractor Analysis:**<br>- **A is Incorrect:** Masking hides a value but keeps its shape (e.g., replacing a name with `[REDACTED]`). The prompt mentions the need to completely remove PII (redaction), and continuous pre-training might still learn patterns from the masked tokens or surrounding context.<br>- **C is Incorrect:** Fine-tuning does not inherently prevent PII leakage; if PII is in the fine-tuning data, it can be memorized and regurgitated.<br>- **D is Incorrect:** Hashing replaces PII with deterministic strings, but the model might learn to associate the hashes with specific contexts, and hashing does not remove the underlying identity pattern. True redaction is safer.<br><br>> **Exam Tip:** Redaction removes sensitive data entirely, while masking only obscures it. Always run PII detection and redaction *before* any FM customization. |
| **### Question 5 - Behavior Tuning vs Knowledge Retrieval**<br><br>An ML team is preparing data for Amazon Bedrock fine-tuning. They have a dataset of 5,000 customer support interactions. The team wants the model to learn a specific behavior: apologizing empathetically before providing a solution.<br><br>The team must ensure the model learns this behavior accurately and consistently updates its internal weights. Which data preparation strategy is the **MOST effective**? (Select ONE)<br><br>- **A)** Provide unlabeled text of all customer support interactions for continuous pre-training.<br>- **B)** Assemble prompt-response pairs where the prompt is the customer query and the completion is the empathetic apology followed by the solution.<br>- **C)** Create a prompt set without responses and let the model generate its own empathetic responses during distillation.<br>- **D)** Store the interactions in a vector store and use RAG to inject empathetic examples at inference. | **Correct Answer:** **B**<br><br>**Correct Option Analysis:**<br>- **B is Correct:** Supervised fine-tuning (SFT) teaches a model a specific behavior or task using labeled prompt-response pairs. Providing the exact desired output (apology + solution) trains the model to adopt this behavior in its weights.<br><br>**Distractor Analysis:**<br>- **A is Incorrect:** Unlabeled text for continuous pre-training absorbs vocabulary and style, but it does not explicitly teach the behavior of pairing an apology with a solution.<br>- **C is Incorrect:** Distillation uses a teacher model to generate responses. If the teacher doesn't already exhibit the empathetic behavior, the student won't learn it.<br>- **D is Incorrect:** RAG injects context at inference time but does not update the model's internal weights to inherently adopt the tone.<br><br>> **Exam Tip:** To teach an FM a specific behavior (like tone or formatting), prepare JSONL prompt-response pairs for supervised fine-tuning. |
| **### Question 6 - Distillation Training Data Generation**<br><br>An e-commerce company wants to compress their large foundation model into a smaller one for edge deployment using Amazon Bedrock model distillation. They have collected a wide variety of user queries that the model needs to handle.<br><br>The team must prepare the training data for the smaller model with the **least operational overhead**. What is the correct data preparation step for this distillation task? (Select ONE)<br><br>- **A)** Use the prompt set to generate responses from the larger teacher model, which will then be used to fine-tune the smaller student model.<br>- **B)** Manually write the ideal responses for each prompt in the set to train the student model.<br>- **C)** Train a separate classification model to filter the prompts before passing them to the student model.<br>- **D)** Embed the prompts using Amazon Titan Embeddings and store them in a vector store for the student model to retrieve. | **Correct Answer:** **A**<br><br>**Correct Option Analysis:**<br>- **A is Correct:** In Bedrock model distillation, the user provides the prompt set. The managed service runs the larger teacher model against these prompts to generate high-quality responses, and these synthetic prompt-response pairs are then used to fine-tune the smaller student model.<br><br>**Distractor Analysis:**<br>- **B is Incorrect:** Manually writing responses defeats the purpose of distillation, which is to transfer knowledge from the teacher model automatically, minimizing manual labeling overhead.<br>- **C is Incorrect:** Training a separate classification model is unnecessary and introduces high operational overhead.<br>- **D is Incorrect:** Vector stores are used for RAG architectures, not for training a distilled model's weights.<br><br>> **Exam Tip:** Distillation automates response generation via the teacher model, drastically reducing the manual labeling overhead for fine-tuning the student. |

Which AWS service can **automatically detect** and assist in redacting these sensitive data types from the unstructured text? They have 1,000 examples of customer reviews paired with the ideal brand-approved responses. The data is static and unlikely to change frequently.<br><br>The solution must update the model's weights to ensure the tone is consistently applied **without relying on prompt engineering**. Which data preparation approach fulfills this requirement? (Select ONE)<br><br>- **A)** Prepare the 1,000 review-response pairs as JSONL files for supervised fine-tuning.<br>- **B)** Assemble a large corpus of unlabeled brand content for continuous pre-training.<br>- **C)** Chunk the brand responses and add them to a vector store for RAG.<br>- **D)** Generate a prompt set for distillation using the larger model. | **Correct Answer:** **A**<br><br>**Correct Option Analysis:**<br>- **A is Correct:** Supervised fine-tuning with prompt-response pairs (JSONL) is the correct way to update model weights to learn a specific behavior or tone, especially when the dataset is static and prompt engineering alone is deemed insufficient.<br><br>**Distractor Analysis:**<br>- **B is Incorrect:** Continuous pre-training with unlabeled text teaches vocabulary and domain knowledge, but it is inefficient for teaching specific prompt-response behaviors like tone matching.<br>- **C is Incorrect:** RAG stores knowledge in a vector store for retrieval but does not update the model's internal weights to adopt a specific tone.<br>- **D is Incorrect:** Distillation is for transferring capabilities from a teacher to a student model to reduce size, not specifically for learning brand tone from labeled examples.<br><br>> **Exam Tip:** When prompt engineering isn't enough to teach a static behavior or tone, prepare JSONL prompt-response pairs for supervised fine-tuning. |
