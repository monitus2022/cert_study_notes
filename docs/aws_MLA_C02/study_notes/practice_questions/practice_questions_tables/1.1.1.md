| **### Question 1 - Distributed Training Data Extraction from Shared File Systems**<br><br>A machine learning engineering team is preparing to run a distributed training job across multiple Amazon SageMaker instances. The training dataset consists of millions of small image files that are currently stored in an on-premises data center.<br><br>The team needs to migrate this data to AWS and make it available to all training instances concurrently with the **lowest operational overhead** and a standard POSIX interface.<br><br>Which storage service should the team use to host the extracted data for the training job? (Select ONE)<br><br>- **A)** Amazon Elastic Block Store (Amazon EBS) with Multi-Attach enabled<br>- **B)** Amazon Simple Storage Service (Amazon S3) mounted via S3 File Gateway<br>- **C)** Amazon Elastic File System (Amazon EFS)<br>- **D)** Amazon FSx for Lustre | **Correct Answer:** **C**<br><br>**Correct Option Analysis:**<br>- **C is Correct:** Amazon EFS is a fully managed, serverless, POSIX-compliant shared file system that can be mounted concurrently by multiple SageMaker training instances.
