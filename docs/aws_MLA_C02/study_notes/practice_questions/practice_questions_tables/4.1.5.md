| **### Question 10 - Detecting Agent Data Drift**<br><br>An agent's performance degrades over time because the distribution of user prompts shifts, causing the agent to select the wrong tool for the job. The team needs an **automated pipeline** to detect this input data drift before it impacts agent coordination. The solution must be **highly scalable**.<br><br>Which architecture meets these requirements? (Select ONE)<br><br>- **A)** Use Amazon CloudWatch generative AI observability to monitor real-time prompt token distributions and set an alarm on token count variance.<br>- **B)** Build a drift detection pipeline using Amazon SageMaker to capture baseline prompt embeddings, compare current traffic embeddings, and alert when the statistical distance exceeds a threshold.<br>- **C)** Configure an AWS Lambda function to check if the correct tool was invoked by reviewing CloudTrail logs and sending an email if the wrong tool is used.<br>- **D)** Use Amazon Bedrock Guardrails to automatically rewrite user prompts so they match the agent's baseline prompt distribution.<br> | **Correct Answer:** **B**<br><br>**Correct Answer Analysis:**<br>- **B is Correct:** Data drift in generative AI applications is detected by comparing the statistical distribution of current input prompt embeddings against a baseline. A SageMaker pipeline can automate this comparison using a suitable statistic (like KL divergence or cosine distance) and alert when the distance passes a threshold.<br><br>**Distractor Analysis:**<br>- **A is Incorrect:** Monitoring prompt token counts via CloudWatch does not detect semantic shifts in the prompt distribution; a prompt can have the same token count but an entirely different meaning.<br>- **C is Incorrect:** Reviewing CloudTrail logs for wrong tool invocations is a reactive, post-failure approach (concept drift detection), not a proactive input data drift detection pipeline.<br>- **D is Incorrect:** Bedrock Guardrails cannot rewrite prompts to force them to match a baseline distribution; Guardrails are for safety, content filtering, and PII redaction.<br><br>> **Key Takeaway:** Proactive data drift detection for generative AI applications requires an automated pipeline comparing baseline and current input prompt embeddings using statistical distances. |
