Category: MLA – Deployment and Orchestration of ML and AI Workflows
A financial services company is assessing the retrieval quality of an Amazon Bedrock Knowledge Base by configuring a retrieve-only RAG evaluation job. Bedrock will invoke the Knowledge Base during the evaluation, and the company plans to use the Context coverage metric to determine whether retrieved content contains the information represented in the expected answers. An AI engineer must create the input prompt dataset in the format and structure supported by Bedrock.

Which of the following should be implemented?


Create a JSONL dataset in which each line contains a conversationTurns object with a prompt containing the evaluation query and referenceContexts containing the expected retrieved passages.

Create a JSONL dataset in which each line contains a conversationTurns object with a referenceResponses field containing the evaluation query and a prompt field containing the expected retrieved passages.

Create a JSONL dataset in which each line contains a conversationTurns object with a prompt containing the evaluation query and referenceResponses containing the expected ground-truth response.

Create a CSV dataset with a prompt column containing the evaluation query and a referenceResponses column containing the expected ground-truth response.
