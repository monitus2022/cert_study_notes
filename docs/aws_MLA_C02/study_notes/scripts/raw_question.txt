Category: MLA – Data Preparation for ML and AI
A startup uses an on-premises MySQL database to store its machine learning (ML) model training data. The decision has been made to migrate the ML data to Amazon Aurora for better scalability and performance.

What is the most suitable approach for migrating ML data from MySQL to Aurora?

Create a custom Python script that extracts the ML data from MySQL, compresses it, and uploads it directly to Aurora via the AWS SDK.
Set up a real-time data replication pipeline between MySQL and Aurora using AWS DMS.
Use AWS Data Transfer Terminal by reserving time at an AWS facility and physically connecting equipment to transfer the ML data into AWS, then load it into Aurora.
Use AWS DMS to perform a homogeneous migration from MySQL to Aurora.
