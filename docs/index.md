## How to read this site

- **Notes** capture the model of a topic: terms, mechanisms, and failure modes.
- **Practice** items test whether that model can be applied under a constraint.
- **Projects** record what was actually built, measured, and rejected.

New sections start with one example page that shows the intended format. Real entries are added as they are written.
