# Task 1.3: Ensure Data Integrity and Prepare Data for Modeling

## Key Concepts
Data integrity ensures high-quality inputs free of missing/erroneous values before modeling. Balance **bias-variance** tradeoff for accurate models. Pre-training bias (model-agnostic) is detected in raw data via **Amazon SageMaker Clarify**, which quantifies fairness, explains predictions, monitors post-training/inference bias against baselines, and generates governance reports for compliance.

**Key pre-training bias metrics**:
- **Class Imbalance (CI)**: Uneven class distribution (numeric/text/image).
- **Difference in Proportions of Labels (DPL)**: Label disparities across groups.

**Mitigation strategies**:
- **Resampling** (up/down-sample) for numeric/time-series regularity.
- **Synthetic data**: Fully generated (no original data use).
- **Data augmentation**: Creates variants from existing data (e.g., flips/rotations).
- Shuffling/randomization (prevents order bias) + train/test splits to reduce prediction bias. *Do not randomize time-series* (preserves sequence for RNNs).

**SageMaker image classification** (CNN, multi-label, transfer learning): Supports augmentation hyperparameters. Preferred inputs: Apache MXNet RecordIO (efficient) or raw .jpg/.png.

**Data quality validation**:
- **AWS Glue DataBrew** + **AWS Glue Data Quality** (uses DQDL). Entry points: Glue Data Catalog or ETL jobs. Measures/monitors quality rules.
- **SageMaker Canvas**: No-code transforms (clean/featurize); supports custom ops and Redshift imports.

**Compliance & protection**:
- Classify/anonymize/mask data. Handle PII/PHI and data residency.
- Encrypt with **AWS KMS**: S3 storage, SageMaker notebooks/volumes (training/processing/endpoints), Glue redaction of sensitive fields. Store credentials in Secrets Manager.

**Data loading for training**:
- Sources: S3 (default), Amazon EFS, Amazon FSx for Lustre.
- Modes: File (copies to EBS, slower) vs. Pipe (streams RecordIO, faster, real-time).

Inference pipelines reuse scikit-learn/Spark ML transformers for consistent preprocessing in real-time/batch predictions.

## Comparisons
| Component | Use Case | vs. Similar |
|-----------|----------|-------------|
| Synthetic data | New samples independent of original | Augmentation (derives from existing; e.g., SageMaker image aug) |
| Pipe mode | Fast streaming (RecordIO) | File mode (full download + per-file processing; slower) |
| EFS | Shared file access | FSx for Lustre (high-perf HPC/ML workloads); both complement S3 |
| Clarify | Bias/explainability pre/post-train | Ground Truth (labeling only); Canvas (transforms, no deep bias metrics) |
| Glue Data Quality | Rule-based monitoring (Catalog/ETL) | DataBrew (visual prep) |
