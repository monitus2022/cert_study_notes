# Task 4.3: Secure AWS Resources (MLA-C01)

## Key Concepts
Security is foundational in ML architectures under the **Shared Responsibility Model**. AWS secures the infrastructure; you secure accounts, data, identities, and configurations. Master AWS accounts: protect the root user (MFA mandatory, no daily use), enforce least privilege, and enable MFA everywhere.

**IAM Fundamentals**: Identities (users, groups, roles) start with zero permissions. Use identity-based policies (attached to users/groups/roles) vs. resource-based policies (e.g., S3 bucket policies). SageMaker requires an **execution role** (IAM role) to call other services on your behalf. Leverage **SageMaker Role Manager** to generate least-privilege roles tailored to ML personas (data scientist, MLOps). SageMaker supports fine-grained actions, resources, and condition keys.

**Network Controls for ML Resources**: Launch SageMaker Studio, notebooks, training jobs, and endpoints inside a private VPC with no internet access. Disable direct internet on Studio/notebooks. Route traffic to S3, SageMaker APIs, and CloudWatch via **VPC interface endpoints** (PrivateLink) so data never leaves the AWS network. Attach endpoint policies and IAM conditions (aws:SourceVpce or source IP) to lock access to specific Studio domains or notebooks. Use security groups and NACLs for isolation; add NAT Gateway only when outbound internet is required for non-VPC-endpoint services. AWS Network Firewall or Gateway Load Balancer can filter traffic.

**Data Protection**: Encrypt at rest with **AWS KMS** (customer-managed keys preferred). SageMaker encrypts S3 model artifacts, EFS (Studio), EBS volumes, and notebooks by default or via KMS. Protect in transit with HTTPS/TLS and SigV4 signing. Enable inter-node encryption for distributed training inside a VPC. For S3 artifacts, turn on versioning + MFA Delete. Associate Git repos (CodeCommit preferred) with notebooks; rotate credentials and require MFA. Use SageMaker Model Registry for governed model versions.

**Monitoring & Compliance**: Enable CloudTrail, CloudWatch, and GuardDuty for audit trails and anomaly detection. SageMaker participates in FedRAMP, HIPAA, etc.; download reports via AWS Artifact. Apply security at every layer of the ML pipeline and CI/CD (least-privilege pipeline roles, no long-lived keys).

## Comparisons
- **IAM Users vs Roles vs Groups**: Users for humans; roles for services/apps (temporary creds); groups for permission sets. Prefer roles + STS over long-term access keys.

- **SageMaker Notebooks vs EC2**: Notebooks default to root access (needed for package installs) but must be locked down with IAM + VPC; EC2 requires explicit grants and SSM/Session Manager instead of SSH.
- **VPC Endpoints vs NAT/Internet Gateway**: Endpoints keep traffic private and free of data-transfer charges for supported services; NAT is fallback only.
