# MLA_C01 Task 2.3: Analyze Model Performance

## Core Evaluation Metrics
Post-training, assess models with metrics matched to problem type. Classification uses **confusion matrix** (TP/TN/FP/FN counts), from which derive:
- **Accuracy**: (TP+TN)/total â€“ overall correctness (trap: fails on imbalanced data).
- **Precision**: TP/(TP+FP) â€“ minimizes false positives.
- **Recall (Sensitivity)**: TP/(TP+FN) â€“ minimizes false negatives.
- **F1 Score**: Harmonic mean of precision/recall â€“ balances both.
- **Specificity**: TN/(TN+FP); **FPR**: FP/(FP+TN).
- **ROC curve** plots TPR vs FPR; **AUC** summarizes (1.0 = perfect, 0.5 = random).

Regression uses **RMSE** (sqrt of mean squared errors â€“ penalizes large errors), **MAE**, **MAPE**. Heat maps visualize confusion or feature correlations. Select metrics by business need (e.g., high recall for fraud detection).

## Overfitting, Underfitting & Convergence
- **Overfitting**: Low train error, high eval error (memorizes noise). Fix: reduce flexibility (fewer features/combinations, smaller n-grams), increase regularization, more data/passes.
- **Underfitting**: High error on both (too simple). Fix: increase flexibility (add domain features/Cartesian products, larger n-grams), decrease regularization, better processing.
Poor accuracy on both often signals insufficient data â€“ add examples. **Convergence issues** (vanishing gradients, saturated activations, exploding loss) diagnosed via tools below. Model fit diagnosis is key to root-causing poor accuracy: tune data volume, features, or hyperparameters.

## AWS Tools for Insights & Debugging
- **SageMaker Clarify**: Post-training bias/fairness metrics + feature attributions for interpretability. Detects bias in data/models; integrates with Model Monitor.
- **SageMaker Canvas**: Auto-scores models (accuracy overviews) for no-code users; embed in QuickSight viz. Simpler than Clarify for quick checks.
- **SageMaker Debugger**: Hooks extract tensors to S3; built-in rules catch overfitting, vanishing gradients, poor convergence. Trigger CloudWatch Events â†’ Lambda actions or SNS alerts. Vs. **TensorBoard** (hosted in SageMaker Domain): visualizes scalars/histograms interactively but less automated rule-based detection.
- **Shadow Testing**: Deploy variant alongside production; compare metrics (latency, accuracy) without user impact. Identifies config/performance issues safely.
- **SageMaker Experiments**: Logs params, metrics, artifacts for reproducible runs. Compare trials via charts/tables; export for stakeholders. Tracks hyperparam searches amid iteration.

## Tradeoffs & Reproducibility
Balance performance vs. training time/cost (e.g., larger instances speed training but raise $). Use Experiments + Debugger for efficient iteration. Always version data/models for reproducibility.
