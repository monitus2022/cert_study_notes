# MLA_C01 Study Notes: Exam Domains Overview

## Domain 1: Data Preparation for ML
Focuses on the first two ML lifecycle steps: data collection and processing. Ensure high-quality inputs by handling missing/erroneous data and optimizing for efficiency.

- **Task 1.1 (Ingest & Store)**: Select AWS storage (S3, EFS, FSx, Glacier) based on access patterns (frequent vs. archival), formats (CSV, Parquet, JSON), structure, cost, and performance. Troubleshoot scalability/capacity issues during ingestion (e.g., Kinesis, Data Firehose, Glue).
- **Task 1.2 (Transform & Feature Engineering)**: Clean/transform via Glue, DataBrew, or SageMaker Data Wrangler. Explore/visualize with QuickSight or SageMaker. Apply encoding (one-hot, label), scaling, and feature techniques; validate/label data.
- **Task 1.3 (Integrity & Modeling Prep)**: Use classification, anonymization, masking. Encrypt via KMS. Validate quality, detect/mitigate bias (SageMaker Clarify) to reduce biased predictions.

**Comparisons**: S3 (object, durable, cheap) vs. EBS (block, low-latency) vs. EFS (file, shared). Batch (Glue) vs. streaming (Kinesis) ingestion.

**Exam Tips/Traps**: Prefer Parquet/ORC for analytics cost/performance. Trap: Ignoring bias checks or choosing storage solely on cost without access patterns. Know when to use SageMaker Processing vs. Glue.

## Domain 2: Model Training & Evaluation
Covers algorithm selection, training, and performance analysis (lifecycle steps 3-4; Well-Architected model development).

- **Task 2.1 (Choose Approach)**: Match built-in SageMaker algorithms (XGBoost, Linear Learner, Image Classification) or AI services (Rekognition, Comprehend, Forecast) to use cases. Factor interpretability (e.g., linear models over black-box).
- **Task 2.2 (Train & Refine)**: Understand training loops, spot/managed spot training for time/cost reduction, model size factors, regularization (L1/L2, dropout). Tune hyperparameters (Bayesian, random search via SageMaker); integrate external models.
- **Task 2.3 (Analyze Performance)**: Metrics (accuracy, F1, RMSE, AUC), baselines, convergence debugging. Use Clarify for bias/feature importance insights.

**Comparisons**: Built-in algorithms (managed, optimized) vs. custom/script mode vs. AI services (no-code, task-specific). Real-time vs. batch transform.

**Exam Tips/Traps**: Hyperparameter impact is high-yieldâ€”know learning rate effects. Trap: Overlooking regularization for overfitting or choosing complex models when interpretability is required. Clarify metrics appear frequently.

## Domain 3: Model Deployment & Operations
Hosts models (lifecycle step 5; Well-Architected deployment). Emphasizes infrastructure selection, scripting, and CI/CD.

- **Task 3.1 (Select Infrastructure)**: Match endpoints (real-time, serverless, multi-model) to requirements. Optimize edge (SageMaker Edge, Neo). Serve real-time (endpoints) vs. batch. Provision compute (instances, inference components).
- **Task 3.2 (Create & Script)**: Use IaC (CloudFormation, CDK), containers (ECS/EKS, SageMaker), auto-scaling policies. Script provisioning and scaling.
- **Task 3.3 (Orchestration & CI/CD)**: Apply CI/CD (CodePipeline, CodeBuild) to ML workflows. Integrate ingestion (Step Functions, Airflow), version control (CodeCommit/Git). Know deployment strategies (blue/green, canary) and rollbacks.

**Comparisons**: Real-time endpoints (low latency) vs. batch transform (throughput) vs. asynchronous. Serverless Inference (auto-scale, cost-effective) vs. provisioned.

**Exam Tips/Traps**: Auto-scaling and rollback are common. Trap: Forgetting multi-model endpoints for cost savings or mismatched deployment to traffic patterns. Know Edge Manager vs. Neo compilation.

## Domain 4: ML Security, Monitoring & Costs
Focuses on inference monitoring, cost/performance optimization, and security (lifecycle step 6).

- **Task 4.1 (Monitor Inference)**: Detect data/model/concept drift. Monitor quality/performance (Model Monitor, CloudWatch). Apply ML Lens design principles.
- **Task 4.2 (Optimize Costs/Infra)**: Track KPIs (latency, throughput, error rates) with CloudWatch, X-Ray. Choose instances (compute-optimized vs. GPU/Inferentia). Use Cost Explorer, budgets, allocation tags; right-size and use Savings Plans/spot.
- **Task 4.3 (Secure Resources)**: IAM roles/policies/groups, S3 bucket policies, SageMaker Role Manager. Network controls (VPC, private endpoints, security groups). Secure CI/CD; leverage SageMaker compliance features (encryption, isolation).

**Comparisons**: CloudWatch (metrics/logs) vs. Model Monitor (ML-specific drift) vs. X-Ray (tracing). On-demand vs. spot vs. reserved instances.

**Exam Tips/Traps**: Drift detection + Clarify integration is key. Trap: Over-provisioning instances or missing least-privilege IAM for SageMaker execution roles. Always encrypt data at rest/transit; know VPC-only modes.

**Overall Exam Strategy**: Questions test service selection by requirements (latency, cost, scale, security). Memorize when to use managed AI services vs. full SageMaker. Total target: lifecycle alignment + Well-Architected pillars. Practice distinguishing similar services and identifying bias/cost/security pitfalls.
