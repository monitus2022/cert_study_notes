### Question 2
A company is evaluating whether migrating its data center workloads to AWS will reduce costs. The company wants a data-driven assessment that estimates the total cost of ownership and provides right-sizing recommendations before migration. Which AWS service should the company use?

A. Migration Evaluator  
B. AWS Application Discovery Service  
C. AWS Application Migration Service  
D. AWS Migration Hub  

<details>
<summary>Click to view Answer & Explanation</summary>

**Correct Answer:** A

**Explanation:**
* **Why A is correct:** Migration Evaluator provides a data-driven business case for AWS migration. It helps estimate costs, identify right-sized AWS resources, and support migration planning.
* **Why distractors are incorrect:**
  * **B (AWS Application Discovery Service):** Collects information about on-premises servers, applications, and dependencies but is not primarily used to create a cost business case.
  * **C (AWS Application Migration Service):** Replicates and migrates servers to AWS; it does not primarily perform migration cost analysis.
  * **D (AWS Migration Hub):** Provides a central place to track migration progress across supported tools and services.

</details>

D. AWS Application Migration Service  

<details>
<summary>Click to view Answer & Explanation</summary>

**Correct Answer:** A

**Explanation:**

### Question 9
A company wants to migrate an application to AWS. The company plans to move the application with minimal changes but wants to replace its self-managed database with a managed AWS database service to reduce administrative effort. Which migration strategy is being used?

A. Replatform  
B. Rehost  
C. Refactor  
D. Retire  

<details>
<summary>Click to view Answer & Explanation</summary>

**Correct Answer:** A

**Explanation:**
* **Why A is correct:** Replatforming involves making limited optimizations to an application during migration, such as moving to a managed database service, without fundamentally changing the application architecture.
* **Why distractors are incorrect:**
  * **B (Rehost):** Moves the application with little or no modification, commonly known as lift and shift.
  * **C (Refactor):** Involves substantially redesigning or re-architecting the application to use cloud-native capabilities.
  * **D (Retire):** Removes an application that is no longer needed instead of migrating it.

</details>
