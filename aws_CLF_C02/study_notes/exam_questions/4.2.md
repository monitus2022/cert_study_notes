### Question 1
A company wants to estimate the monthly cost of running a new application before deploying it. The application will use Amazon EC2, Amazon RDS, and Amazon S3 in a specific AWS Region. Which AWS service should the company use?

A. AWS Pricing Calculator  
B. AWS Cost Explorer  
C. AWS Budgets  
D. AWS Cost and Usage Reports  

<details>
<summary>Click to view Answer & Explanation</summary>

**Correct Answer:** A

**Explanation:**
* **Why A is correct:** AWS Pricing Calculator helps estimate the cost of planned AWS workloads by allowing users to select services, configurations, Regions, and usage assumptions.
* **Why distractors are incorrect:**
  * **B (AWS Cost Explorer):** Analyzes historical and current AWS costs and usage after resources are running.
  * **C (AWS Budgets):** Tracks costs or usage against defined thresholds and sends notifications.
  * **D (AWS Cost and Usage Reports):** Provides detailed billing and usage data for analysis after AWS usage occurs.

</details>

### Question 2
A development team wants to receive an email when its monthly AWS charges exceed 80% of a planned budget. The company does not want the service to automatically terminate resources. Which AWS service should the team use?

A. AWS Budgets  
B. AWS Cost Explorer  
C. AWS Billing Conductor  
D. AWS Pricing Calculator  

<details>
<summary>Click to view Answer & Explanation</summary>

**Correct Answer:** A

**Explanation:**
* **Why A is correct:** AWS Budgets can monitor costs, usage, reservations, and Savings Plans, and can send notifications when defined thresholds are reached. A budget alert does not automatically terminate resources unless additional actions are configured.
* **Why distractors are incorrect:**
  * **B (AWS Cost Explorer):** Provides interactive cost and usage analysis but is not primarily used to configure budget threshold notifications.
  * **C (AWS Billing Conductor):** Helps organizations create customized billing views and rates for internal chargeback or showback.
  * **D (AWS Pricing Calculator):** Estimates future costs before deployment and does not monitor actual account spending.

</details>
