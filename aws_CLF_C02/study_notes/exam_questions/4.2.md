A. Delivering detailed billing and usage data to an Amazon S3 bucket  
B. Including multiple billing dimensions for detailed analysis  
C. Sending automatic notifications when a budget threshold is reached  
D. Estimating the cost of an AWS workload before deployment  
E. Applying custom internal rates to business-unit invoices  

<details>
<summary>Click to view Answer & Explanation</summary>

**Correct Answers:** A and B

**Explanation:**
* **Why A is correct:** AWS Cost and Usage Reports can deliver reports to Amazon S3 for storage and downstream processing.
* **Why B is correct:** The reports contain detailed billing and usage dimensions, which can be used to analyze costs by account, service, usage type, and other available attributes.
* **Why C is incorrect:** AWS Budgets provides budget threshold notifications.
* **Why D is incorrect:** AWS Pricing Calculator estimates costs for planned workloads.
* **Why E is incorrect:** AWS Billing Conductor supports custom internal pricing and chargeback views.
