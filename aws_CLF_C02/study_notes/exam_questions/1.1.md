### Question 1
A company is launching an online learning platform for customers in North America, Europe, and Asia. The company wants users to access the application with low latency regardless of their location. Which AWS capability best supports this requirement?

A. AWS Global Infrastructure  
B. AWS Auto Scaling  
C. AWS CloudTrail  
D. AWS Direct Connect  

<details>
<summary>Click to view Answer & Explanation</summary>

**Correct Answer:** A

**Explanation:**
* **Why A is correct:** AWS Global Infrastructure includes Regions and Availability Zones around the world, allowing organizations to deploy applications closer to their customers and improve global reach and response times.
* **Why B is incorrect:** AWS Auto Scaling adjusts resource capacity based on demand but does not provide global geographic deployment.
* **Why C is incorrect:** AWS CloudTrail records AWS API activity for governance, compliance, and auditing.
* **Why D is incorrect:** AWS Direct Connect provides a dedicated network connection between an on-premises environment and AWS; it does not provide global application distribution.

</details>
