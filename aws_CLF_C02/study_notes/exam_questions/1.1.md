### Question 1
A company is launching an online learning platform for customers in North America, Europe, and Asia. The company wants users to access the application with low latency regardless of their location. Which AWS capability best supports this requirement?

A. AWS Global Infrastructure  
B. AWS Auto Scaling  
C. AWS CloudTrail  
D. AWS Direct Connect  

<details>
<summary>Click to view Answer & Explanation</summary>

**Correct Answer:** A

**Explanation:**
* **Why A is correct:** AWS Global Infrastructure includes Regions and Availability Zones around the world, allowing organizations to deploy applications closer to their customers and improve global reach and response times.
* **Why B is incorrect:** AWS Auto Scaling adjusts resource capacity based on demand but does not provide global geographic deployment.
* **Why C is incorrect:** AWS CloudTrail records AWS API activity for governance, compliance, and auditing.
* **Why D is incorrect:** AWS Direct Connect provides a dedicated network connection between an on-premises environment and AWS; it does not provide global application distribution.

</details>

### Question 4
A financial services company wants its customer-facing application to continue operating if one data center experiences a hardware or power failure. Which AWS Global Infrastructure design should the company use?

A. Deploy resources across multiple Availability Zones in an AWS Region  
B. Deploy all resources in a single Availability Zone  
C. Use AWS CloudTrail in one Availability Zone  
D. Use AWS Direct Connect with one network circuit  

<details>
<summary>Click to view Answer & Explanation</summary>

**Correct Answer:** A

**Explanation:**
* **Why A is correct:** Availability Zones are separate locations within an AWS Region and are designed to be isolated from failures in other Availability Zones. Deploying across multiple Availability Zones can improve application availability.
* **Why B is incorrect:** A single Availability Zone can be a single point of failure for the application.
* **Why C is incorrect:** AWS CloudTrail provides activity logging and does not by itself provide application redundancy.
* **Why D is incorrect:** A single AWS Direct Connect circuit can itself become a point of failure and does not distribute application resources across Availability Zones.

</details>

### Question 10
A company is moving an application to AWS and wants to improve availability while automatically responding to changes in user demand. Which two actions should the company take? (Select TWO)

A. Use AWS Auto Scaling to adjust compute capacity  
B. Deploy application resources across multiple Availability Zones  
C. Deploy all resources in one Availability Zone  
D. Provision enough fixed capacity for the highest expected demand  
E. Use AWS CloudTrail as the application load-balancing mechanism  

<details>
<summary>Click to view Answer & Explanation</summary>

**Correct Answers:** A and B

**Explanation:**
* **Why A is correct:** AWS Auto Scaling automatically adjusts capacity as demand changes, supporting elasticity and consistent application performance.
* **Why B is correct:** Multiple Availability Zones provide fault isolation and improve availability if one Availability Zone has a disruption.
* **Why C is incorrect:** Using one Availability Zone creates a single point of failure.
* **Why D is incorrect:** Fixed capacity for peak demand can increase costs and does not provide the elasticity of automatically adjusting resources.
* **Why E is incorrect:** AWS CloudTrail records AWS API activity and is not an application load-balancing mechanism.

</details>
