# CLF-C02 Study Notes: AWS Technical Resources and Support Options

## 1. AWS Support Resources

AWS provides several resources to help customers design, deploy, operate, and troubleshoot AWS environments. Support is not limited to fixing service outages; it can also include architectural guidance, best practices, account assistance, and proactive planning.

### AWS Documentation

Use AWS documentation for:

- Service overviews and concepts
- Getting started tutorials
- Configuration instructions
- API and command-line references
- Security and best-practice guidance
- Troubleshooting information

**Exam tip:** If a question asks where to find step-by-step instructions for deploying or configuring an AWS service, the best answer is usually **AWS Documentation**.

### AWS Well-Architected Framework

The AWS Well-Architected Framework provides best practices for designing and reviewing cloud workloads.

It evaluates workloads across six pillars:

1. Operational excellence
2. Security
3. Reliability
4. Performance efficiency
5. Cost optimization
6. Sustainability

Use the framework to identify risks and improve an existing or planned architecture.

**Exam tip:** Questions asking about AWS architectural best practices or reviewing a workload commonly point to the **AWS Well-Architected Framework**.

### AWS re:Post

AWS re:Post is a community-driven question-and-answer service where customers can:

- Ask specific technical questions
- Search previously answered questions
- Learn from AWS experts and other AWS customers
- Discuss implementation issues and use cases

**Compare:**

| Resource | Best use |
|---|---|
| AWS Documentation | Official service instructions and reference material |
| AWS Well-Architected Framework | Architectural best practices and workload reviews |
| AWS re:Post | Community questions and practical troubleshooting |
| AWS Support | Direct assistance through support cases |

### AWS Training and Certification

AWS Training and Certification resources help customers build AWS knowledge and practical experience. Examples include:

- AWS Skill Builder
- Digital courses
- Exam preparation
- Hands-on labs
- AWS Certification programs

These resources are for learning and skills development, rather than opening a technical support case.

### AWS Whitepapers and Blogs

- **AWS whitepapers:** Detailed guidance, architectural recommendations, and best practices
- **AWS blogs:** Announcements, tutorials, implementation examples, and service-specific guidance

## 2. AWS Support Plans

AWS Support plans provide different levels of technical assistance and tools. The exact features and pricing vary by plan, so exam questions often test which plan provides a particular capability.

Common support plan categories in the exam include:

- Basic
- Developer
- Business
- Enterprise On-Ramp
- Enterprise

> AWS support-plan names and features can change. For the exam, focus on the distinctions emphasized in the AWS exam material.

### Basic Support

Basic Support is available to all AWS customers at no additional charge.

It includes access to:

- Customer service
- Account and billing assistance
- Support forums
- Service Health Dashboard
- AWS documentation
- Whitepapers
- Best-practice guides

Basic Support does **not** provide general one-on-one technical support from AWS engineers.

### Developer Support

Developer Support is intended for development and testing environments.

It provides:

- Technical support
- Unlimited technical support cases, according to the exam content
- Access to the seven core AWS Trusted Advisor checks
- Access to the AWS Personal Health Dashboard

**Exam tip:** If asked for the most cost-effective plan that provides technical support with an unlimited number of cases, select **Developer Support** rather than Basic.

### Business Support

Business Support is intended for production workloads and provides broader technical assistance.

Features include:

- Technical support
- Use-case guidance
- AWS Trusted Advisor checks
- AWS Support API
- AWS Personal Health Dashboard
- Third-party software support
- Help with Amazon EC2 operating systems and configuration
- Assistance with common third-party software running on AWS
- Infrastructure Event Management for an additional fee

Business Support is generally the most cost-effective plan that provides access to the **AWS Support API** for programmatic support-case management.

### Enterprise On-Ramp and Enterprise Support

Enterprise-level plans are intended for organizations with critical or large-scale workloads.

Enterprise Support provides capabilities such as:

- 24/7 technical support from AWS engineers
- A designated Technical Account Manager (TAM)
- Proactive and preventative guidance
- AWS subject-matter experts
- Concierge-style assistance
- Tools and programs to help manage the health of the environment
- Access to proactive programs such as Well-Architected Reviews and Operations Reviews

Some enterprise-oriented capabilities may also be available through Enterprise On-Ramp, but Enterprise Support provides the broadest level of assistance.

### Support Plan Comparison

| Capability | Basic | Developer | Business | Enterprise |
|---|---:|---:|---:|---:|
| Customer service and billing/account assistance | Yes | Yes | Yes | Yes |
| Documentation, whitepapers, forums | Yes | Yes | Yes | Yes |
| General technical support cases | No | Yes | Yes | Yes |
| Unlimited technical support cases | No | Yes, per exam framing | Yes | Yes |
| Seven core Trusted Advisor checks | No | Yes | Yes | Yes |
| Broader Trusted Advisor capabilities | No | Limited | Yes | Yes |
| AWS Support API | No | No | Yes | Yes |
| Third-party software support | No | No | Yes | Yes |
| Use-case guidance | No | Limited | Yes | Yes |
| Technical Account Manager | No | No | No | Yes |
| Proactive reviews and programs | No | No | Generally no | Yes |

## 3. AWS Trusted Advisor

AWS Trusted Advisor inspects an AWS environment and identifies opportunities to improve it.

It can provide recommendations related to:

- Cost optimization
- Security
- Fault tolerance and reliability
- Performance
- Service limits

Examples of recommendations may include:

- Identifying underutilized resources
- Detecting security-group risks
- Finding opportunities to reduce costs
- Identifying service-limit concerns
- Improving reliability and performance

### Trusted Advisor Access

- Basic Support: limited or no access to the core checks, depending on the feature
- Developer Support: access to the seven core Trusted Advisor checks
- Business and Enterprise Support: broader Trusted Advisor functionality

**Exam trap:** Trusted Advisor is a recommendation and inspection tool. It does not automatically redesign or repair the environment.

## 4. AWS Health Services

### AWS Personal Health Dashboard

The **Personal Health Dashboard** provides a personalized view of AWS service health events that may affect a customerâ€™s resources.

It can alert customers when:

- Their AWS resources are affected
- A service event impacts their account
- Maintenance or other account-specific events require attention

### AWS Service Health Dashboard

The **Service Health Dashboard** shows the general status of AWS services and Regions. It is publicly available and is not limited to a particular customer account.

### Comparison

| Service | Purpose |
|---|---|
| Service Health Dashboard | General, public status of AWS services |
| Personal Health Dashboard | Personalized events affecting a customerâ€™s resources |

**Exam tip:** If the question describes an alert specific to your AWS resources or account, choose **Personal Health Dashboard**.

## 5. AWS Support API

The AWS Support API allows eligible customers to interact with AWS Support programmatically.

Possible uses include:

- Creating and managing support cases
- Checking the status of support cases
- Accessing Trusted Advisor operations
- Automating support workflows

The Support API is associated with **Business and Enterprise-level support** in the exam material.

**Exam trap:** Do not confuse the AWS Support API with general AWS service APIs. It is specifically used for AWS Support and related operations.

---

## 6. Technical Account Manager

A Technical Account Manager, or **TAM**, is a designated AWS technical advisor for eligible enterprise customers.

A TAM can help with:

- Understanding the customerâ€™s AWS environment
- Coordinating AWS resources and subject-matter experts
- Proactive planning
- Preventing issues before they occur
- Reviewing operational practices
- Preparing for major events or migrations
- Recommending relevant AWS programs and services

**Exam tip:** A TAM is associated with **Enterprise Support**, not Basic, Developer, or standard Business Support.

---

## 7. Infrastructure Event Management

Infrastructure Event Management helps customers plan for major events that could place unusual demand on their infrastructure.

Examples include:

- Product launches
- Large marketing campaigns
- Migrations
- Major sales events
- Significant traffic increases

According to the exam material, customers with Business Support may access Infrastructure Event Management for an additional fee. Enterprise customers receive broader proactive support capabilities.

## 8. Other AWS Assistance Options

### AWS Abuse Team

The AWS Abuse Team handles reports involving suspected abuse of AWS resources, such as:

- Spam
- Denial-of-service activity
- Malicious or illegal activity
- Security abuse originating from AWS resources

This team is not the general destination for billing questions or normal technical troubleshooting.

### Billing and Account Support

Use billing or account support for issues such as:

- Unexpected charges
- Payment problems
- Account access
- Account activation
- Service quotas or account-related concerns

### Premium AWS Support

Premium support refers to paid support plans that provide technical assistance beyond the free Basic Support level.

Use premium technical support for:

- Architecture and configuration guidance
- Troubleshooting
- Production-impacting issues
- Support cases requiring AWS engineers

### AWS Managed Services

AWS Managed Services can help customers operate and manage AWS infrastructure. This is different from simply consulting AWS documentation or asking a community question.

**Compare:**

| Option | Main purpose |
|---|---|
| AWS Support | Technical and account assistance |
| AWS Managed Services | Ongoing management and operation of AWS environments |
| AWS Professional Services | Project-based consulting and implementation assistance |
| AWS Partner Network | Assistance from AWS-approved partner organizations |

---

## 9. AWS Partner Network

The **AWS Partner Network**, or APN, is a global community of AWS partners that provide products and services related to AWS.

AWS Partners may offer:

- Consulting
- Migration assistance
- Managed services
- Security solutions
- Software products
- Implementation services
- Industry-specific expertise

Use an AWS Partner when specialized consulting, implementation, software, or managed services are needed.

**Exam tip:** If a scenario asks for help from an external organization with AWS expertise, migration services, or a specialized solution, consider an **AWS Partner**.

---

## 10. Choosing the Correct Resource

| Scenario | Best resource |
|---|---|
| Learn how to deploy an AWS service | AWS Documentation |
| Find architectural best practices | AWS Well-Architected Framework |
| Ask a detailed community question | AWS re:Post |
| Learn AWS concepts and gain hands-on experience | AWS Skill Builder and AWS Training |
| Check general AWS service availability | Service Health Dashboard |
| Check whether your resources are affected by an AWS event | Personal Health Dashboard |
| Automate support case management | AWS Support API |
| Receive designated enterprise technical guidance | Technical Account Manager |
| Review cost, security, reliability, and performance opportunities | AWS Trusted Advisor |
| Get migration or implementation assistance | AWS Partner Network or AWS Professional Services |
| Report suspected malicious use of AWS | AWS Abuse Team |
| Resolve payment or account issues | Billing and Account Support |

# Exam Tips and Common Traps

- **Basic Support is free**, but it does not provide general one-on-one technical troubleshooting.
- **Developer Support** is the most cost-effective plan in the transcript that provides technical support with unlimited support cases.
- **Business Support** is the most cost-effective option listed for access to the **AWS Support API**.
- **Trusted Advisor** identifies recommendations; it does not automatically fix all issues.
- **Personal Health Dashboard** is account-specific; **Service Health Dashboard** shows general AWS service status.
- **Enterprise Support** is associated with a designated **Technical Account Manager**.
- **Well-Architected Framework** is for architectural reviews and best practices, not for opening technical support cases.
- **AWS re:Post** is community support, not guaranteed direct AWS engineering support.
- Use **AWS Documentation** for official deployment instructions.
- Use the **AWS Abuse Team** for suspected abuse, not for ordinary technical support.
- Use **billing/account support** for charges, payments, and account issues.
- An AWS Partner can provide consulting, migration, managed services, or specialized software assistance.

# Practice Questions

## Question 1

A company wants the most cost-effective AWS Support plan that provides access to the AWS Support API for programmatic support-case management. Which plan should the company choose?

A. Basic  
B. Developer  
C. Business  
D. Enterprise  

**Answer: C. Business**

**Explanation:** Business Support is the most cost-effective option listed that provides access to the AWS Support API. Enterprise Support also provides this capability but is more expensive.
